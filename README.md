# Password Generator

A simple password generator made using HTML, CSS, and JavaScript.

This project allows users to generate random passwords by choosing the password length and the types of characters they want to include.

## Features

* Generate random passwords
* Choose password length
* Include uppercase letters
* Include lowercase letters
* Include numbers
* Include symbols
* Simple and clean interface
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How It Works

The user first selects the password length and the character types they want to use.

When the **Generate Password** button is clicked, JavaScript checks which options are selected and creates a character pool from those options.

It then randomly selects characters from the pool until the selected password length is reached.

The generated password is displayed in the password input field.
